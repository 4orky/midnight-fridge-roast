The brief: roast a smart fridge that locks itself at midnight, in a single spoken line. Eleven hand-written candidates were scored against the brief and the strongest one won; `main.py` assembles that winning line, checks it against the 1–200 character single-line gate, and drops it into `/output/entry.txt`.

The winning line:

> Midnight hits and my fridge goes full Fort Knox — guarding food I bought from me, the burglar who paid for it.

## How to run

```bash
python3 ./main.py
```

That prints the character count and leaves the entry at `/output/entry.txt`.
